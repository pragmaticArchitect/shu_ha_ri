# Information Product Specification (INFOPS)

> **Status — PRE-P01 SCAFFOLD.** This site is the initial project repository. It is **not** an approved INFOPS 0.1 specification, Product qualification framework, conformance standard, or maturity catalogue.

INFOPS is intended to define what qualifies as an **Information Product**, consistent with the generic Product semantics of **BPS/PIN** and analytical meaning defined by **GEARM**.

The work will separately develop Information Product characteristics (**INFOPCH**) and evidence-based **Product Maturity-Driven Development (PMDD)** guidance for human and machine assessors.

Start with the [programme and roadmap](./specification/roadmap.md), [authority map](./foundations/authority-map.md), and [qualification boundary planning page](./ontology/qualification-boundary.md).

The HDIP DII reference implementation is a downstream companion workstream, **not** part of the normative qualification definition.
