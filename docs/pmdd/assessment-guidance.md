# Human and AI Agent PMDD guidance — planned

For each future INFOPCH characteristic, assessors should have an inspectable assertion, positive and negative criteria, edge cases, admissible evidence signals, applicability, agent decision rules, and clear escalation of unresolved or judgment-dependent cases.

Proposed assessment vocabulary for discussion: `MET`, `PARTIAL`, `NOT_MET`, evidence-justified `NOT_APPLICABLE`, with a separate `NOT_ASSESSABLE` qualification-precondition result. Weights, thresholds and governance obligations have **not** been frozen for INFOPS.

Assessments are expected to be version-bound, evidence-referenced and reproducible where possible. Automated assessment is not the same as accountable assurance, Product qualification or delegated authority.
