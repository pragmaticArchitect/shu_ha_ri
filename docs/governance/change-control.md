# Change control

Until INFOPS-P01 starts, documents in this repository are **informative planning content**. Normative status requires an explicit reviewed release decision, documented provenance, version identity and cross-artifact reconciliation.

Future changes should be classified as: informational; proposed; normative draft; or frozen/released. Do not present unapproved characteristics or conformance rules as current authority.
