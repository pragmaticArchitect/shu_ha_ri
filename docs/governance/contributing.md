# Contributing

Use a branch and pull request for changes. Include the conceptual authority affected, rationale, positive/negative examples, expected impact on descriptors, PMDD and HDIP/UPOS boundaries, and any tests.

Run `npm run validate`. Once dependencies are installed, also run `npm run build`. Do not submit copyrighted material or reuse AIPS text/visual assets without checking the applicable permissions.
