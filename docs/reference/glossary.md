# Working terminology

| Term | Working meaning / authority |
|---|---|
| BPS / PIN | Generic Product ontology and intrinsic nature |
| GEARM | Generic Enterprise Analytics Reference Model, authority for analytical Information meanings |
| GEARA | Generic Enterprise Analytics Reference Architecture |
| Information Proposition | GEARM concept, not equivalent to Information Product qualification |
| INFOPS | Proposed Information Product family specification |
| INFOPCH | Proposed Information Product characteristic catalogue; count TBD |
| PMDD | Product Maturity-Driven Development; applies after qualification |
| HDIP | Holistic Data, Information and Intelligence Platform |
| UPOS | Universal Productization Operating System |
| HPD | HDIP Product Descriptor, an operational projection and not generic Product authority |

These entries are navigational reminders, not replacements for the cited authorities.
