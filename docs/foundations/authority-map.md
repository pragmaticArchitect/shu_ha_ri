# Authority boundaries to preserve

| Referenced system | Authority / relevance |
|---|---|
| BPS / PIN | Generic Productness, intrinsic nature, value-bearing essence, Product promise and identity |
| GEARM | Information Need, Information Proposition, analytical semantics, formation, outcomes and related Information meanings |
| GEARA | Generic enterprise analytics architectural responsibilities |
| INFOPS (proposed) | Information Product family qualification, characteristics and applicable family contracts |
| HDIP-CLA | Holistic governed Data / Information / Intelligence Platform responsibilities and realization Profiles |
| UPOS | Cross-family Productization/experience vision, including governed self-service |
| AIPS / GEAIRM / GEAIRA | AI family and Intelligence domain boundaries (not redefined by INFOPS) |
| External DPROD / DPDS | Adopted external Data Product semantics/deployment contracts; not to be duplicated here |

This is an initial planning inventory, not a new cross-specification authority contract.
