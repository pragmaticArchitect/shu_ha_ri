# HDIP-RI 0.1 companion track

A deliberately small, runnable HDIP Data–Information–Intelligence Wormhole demonstrator is planned separately from INFOPS normative development.

The demonstrator should test real semantic grounding, governed discovery, independently qualified Products, versioned evidence, and self-service pure consumption versus optional Product creation. No implementation code is bundled in the INFOPS scaffold.
