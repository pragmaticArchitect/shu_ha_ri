# INFOPS 0.1 programme overview

**Planning status:** P01 Stage 2 working draft (non-normative). Version `0.1` names the intended specification line, not an already published normative baseline.

P01-S02 tests ten hypotheses and 36 hypothetical cases without establishing normative qualification. See [PIN falsification](../ontology/p01-stage-02-pin-differentiation-falsification.md).

Proposed workstreams: Product ontology/qualification; INFOPCH characteristics; human and AI Agent assessment guidance; PMDD scoring and evidence; Product-family descriptors; formalization/testing; release readiness.

**Architectural constraint:** INFOPS shall not silently redefine Productness (BPS/PIN), Information semantics (GEARM), analytics architecture (GEARA), or HDIP's frozen logical responsibilities. Any future normative requirements require explicit review and versioning.
